Featured Project: Perfumery Landing Page

**Client:** Local artisanal perfumery startup (Ciudad Quesada, Costa Rica)

**Objective:** Create a responsive, accessible landing page focused on conversion through a premium contact hub.
**Key Features:**
-  Minimalist black & gold aesthetic
-  Mobile-first responsive design
-  WCAG 2.1 Level A compliant
-  Theme preference persistence (localStorage)
-  Single Responsibility Principle applied

**Live Demo:** *[Coming soon]*

**Technical Highlights:**
✅ Semantic HTML5 structure
✅ CSS Grid for product showcases
✅ Flexbox for contact hub navigation
✅ Dark/Light mode toggle with persistence
✅ Keyboard navigation support
✅ High contrast color scheme (4.5:1 ratio)
